# KSF Visual Validation

Use deterministic test data and no secrets. Review relevant screens at 390 x 844
and 1440 x 900, including long values, empty/error/loading states, open menus or
modals, keyboard focus, and dark mode. Playwright is the preferred future
automation path; until configured, document the manual viewport checks actually
performed.
