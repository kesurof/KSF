# Documentation KSF

Cette documentation complete `README.md` et `AGENTS.md` pour le developpement du
depot. Les regles d'exploitation utilisateur restent dans le README principal.

- `contribution/` : workflow, versionnement et preparation GitHub du depot.
- `checklists/` : controles avant implementation, livraison et revue UI.
- `templates/` : modeles a copier et adapter pour les changements importants.
- `webui/` : conventions propres a l'interface d'administration.

Les documents de reference doivent rester coherents avec le code et les skills
OpenCode. Une regle devenue fausse doit etre corrigee ou supprimee.

Les prerequis et le point d'entree de validation locale sont documentes dans
`contribution/local-validation.md`.
